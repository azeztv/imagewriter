# عبد الرضا شهلائي — "جنرال الظل" الإيراني — Motion Graphics (After Effects)

**BUILD SHAHLAEI 2026-11-08-A**

## التشغيل
1. فك الضغط مع الحفاظ على المجلدات (`shahlai/` و`channel-guide/` جنب بعض).
2. ثبّت خط **Neue Haas Grotesk Bloomberg** (Black / Bold / Regular).
3. افتح مشروع After Effects **جديد فاضي** → `File > Scripts > Run Script File…` → `build_shahlai.jsx`.
4. أول سطر في الرسالة لازم يكون `BUILD SHAHLAEI 2026-11-08-A`. أي ملاحظات في `build_log.txt` جنب السكريبت.
5. (اختياري) `audio/music.mp3` موسيقى من مكتبة القناة → تتحط تلقائياً -20 dB.

## الستايل
إنفوجرافيك فلات زي الريفرينس بألوان القناة (برتقالي/رمادي/أبيض) — خلفيات فاتحة مع شبكة نقط، ومشهد الصورة على خلفية غامقة.
الخرائط حدود حقيقية (Natural Earth 1:10m) — من غير أسماء دول.
كل مشهد له "كاميرا" بطيئة وفي آخره غطسة على نقطة التركيز ثم مسحة برتقالي يمين←شمال للمشهد اللي بعده.
العنوان الدائم فوق يمين طول الفيديو.
