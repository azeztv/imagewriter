# مبادرة السعودية الخضراء — Motion Graphics (After Effects)

## التشغيل
1. فك الضغط مع الحفاظ على شكل المجلدات (`green-initiative/` و`channel-guide/` جنب بعض).
2. ثبّت خط **Neue Haas Bloomberg** (Black / Bold / Regular).
3. ضع الملفات الرسمية (اختياري، وإلا يظهر مكانها Placeholder):
   - `assets/crown_prince.png` — صورة ولي العهد الرسمية
   - `assets/saudi_flag.png` — العلم الرسمي
4. في After Effects 2023 أو أحدث: `File > Scripts > Run Script File…` واختر `build_green_initiative.jsx`.
5. يفتح الكومب `GREEN_INITIATIVE_MAIN` (1920×1080، 25fps) وفيه الصوت وطبقة دليل السيف إريا (Guide Layer لا تظهر في الريندر).
