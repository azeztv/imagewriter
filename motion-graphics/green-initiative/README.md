# مبادرة السعودية الخضراء — Motion Graphics (After Effects)

**BUILD 2026-11-08-M**

## التشغيل
1. فك الضغط في مجلد جديد مع الحفاظ على شكل المجلدات (`green-initiative/` و`channel-guide/` جنب بعض).
2. ثبّت خط **Neue Haas Grotesk Bloomberg** (Black / Bold / Regular).
3. (اختياري) ضع:
   - `assets/crown_prince.png` — صورة ولي العهد الرسمية
   - `assets/saudi_flag.png` — العلم الرسمي
   - `audio/music.mp3` — موسيقى من مكتبة القناة (تتحط تلقائياً -20 dB)
4. افتح مشروع After Effects **جديد فاضي** → `File > Scripts > Run Script File…` → `build_green_initiative.jsx`.
5. أول سطر في الرسالة لازم يكون `BUILD 2026-11-08-M`. أي ملاحظات في `build_log.txt` جنب السكريبت.

## الفكرة
"من خطط على ورق إلى زراعة ملايين الأشجار": كل مشهد مجسم مصغّر على ورق هندسي —
يترسم بالقلم الرصاص أولاً ثم يطلع المجسم الحقيقي من الرسمة ويقع ظله على الورق.
ستايل موحّد: ورق أبيض دافئ، إضاءة شمس آخر النهار، توهّج برتقالي (لون القناة).

## اللي بيبنيه السكريبت
- كاميرا 3D سينمائية لكل مشهد (قوس + اهتزاز يد خفيف + دفعة للأمام مع الانتقال) وعمق ميدان وMotion Blur.
- طبقات عمق: ورق نضيف (بعيد) + المجسم (قريب) + الظل الأصلي يظهر لحظة نزول المجسم.
- الانتقالات: لفّة سريعة على الترابيزة داخل القسم، ومسحة برتقالي عند تغيير القسم (الأهداف / الخطط / الإنجازات / الرياض / الختام).
- الكول أب: نظام واحد، يمين الكادر داخل السيف إريا، المحاذاة يحسبها AE وقت الريندر (Expressions).
  التاج 50 · العناوين 80 · الكلمات 58 · الرقم الأساسي 180 برتقالي · الثانوي 140 أبيض · الوحدات 70.
- إفكتات حسب المشهد: سحب (الافتتاح)، رمل مع الريح، مطر من السحابة + برق، دخان يتقلّب ويخف (الانبعاثات)،
  أشجار تطلع وتتهز، لمعة على المجسمات، توهّج الشاشة، خطوط مسح (1150)، ضباب حرارة يختفي (الرياض).
- صوت: VO + مؤثرات (قلم، طلوع، سويش، وووش، عدّاد، خبطة، مطر، رعد، ريح) + مكان للموسيقى.
